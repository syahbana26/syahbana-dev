# 🎮 Syahbana.dev Portfolio Website

Website portofolio pribadi interaktif bergaya *retro gaming* / *cyberpunk* yang dibuat oleh **Sudais Lifasyahbana**, seorang mahasiswa Teknik Informatika di Universitas Trunojoyo Madura (UTM).

## ✨ Fitur Utama

- **Start Experience Overlay**: Fitur sambutan awal dengan tombol interaktif untuk mengaktifkan *Background Music* (BGM) dan efek suara (SFX) khas game.
- **Game HUD Status Bar**: Menampilkan status player ala RPG (HP, MP, dan Level).
- **Player Profile & Inventory**: Menampilkan profil pribadi serta "Equipped Gear & Inventory" interaktif.
- **Cyberpunk & Gaming Theme**: Desain antarmuka gelap dengan aksen neon, font khusus (Orbitron, Audiowide, Rajdhani, Share Tech Mono), serta elemen melayang (*floating items*).
- **Responsive Design**: Tampilan yang optimal di berbagai perangkat, baik desktop maupun *mobile*.

---

## 🛠️ Tech Stack

- **HTML5**: Struktur halaman web.
- **CSS3**: Styling kustom, variabel CSS, animasi, dan layout modern (Flexbox/Grid).
- **JavaScript (Vanilla)**: Logika interaktif, kontrol audio, dan navigasi.
- **FontAwesome & Google Fonts**: Ikon dan tipografi bertema sci-fi/gaming.
- **Assets**: Audio latar belakang (*BGM*) dan efek suara (*SFX*).

---

## 🚀 Cara Menjalankan Project

1. Clone atau download repository ini ke komputer Anda:
   ```bash
   git clone https://github.com/username/example-porto.git
   ```
2. Masuk ke direktori project:
   ```bash
   cd example-porto
   ```
3. Buka file **`index.html`** langsung di web browser pilihan Anda (Chrome, Firefox, Edge, dll).
   *Atau gunakan ekstensi **Live Server** di Visual Studio Code untuk pengalaman development yang lebih mulus.*
